# MGS Peace Walker（Master Collection）繁體中文模組

目前版本：**Beta 0.4**（測試階段，**AI 協助製作**）

> **本繁體中文模組由 AI 製作**：翻譯、程式與文件由 AI（Anthropic 的 Claude）協助製作，並經製作者逐步檢視與修正；仍可能有誤譯、不通順或用詞不一致，歡迎回報。

> **本繁體中文模組只適用於日文版**（以日文版為基礎，需搭配日文語言包）。

非官方的玩家自製繁體中文模組，以日文版為翻譯來源，適用於 Steam 的《METAL GEAR SOLID: PEACE WALKER》（Master Collection 版）。

## 繁體中文模組內容
- 遊戲內文字（選單、任務、劇情字幕、簡報錄音帶、道具與武器說明等）。
- 字型：新增繁體字形，標點採台灣式全形置中。
- 圖片：前情提要、章節標題、Boss 與載具登場標題卡、開頭法律頁。
- 影片（選用，預設不安裝）：遊戲裡有 5 支只有文字的影片，繁體中文模組會把中文字幕燒進影片裡，共 10 個檔案（每支各有 720p 與 1080p 兩種畫質）：
  - 康德引言卡：遊戲開頭、黑底白字的《永久和平論》引言（檔案最小）。
  - 工作人員名單：製作人員名單的標題與職稱頁。
  - 捲動名單：片尾捲動的製作名單（片長最長、檔案最大，處理最久）。
  - 兩部年表：前情提要的歷史年表（共 2 支影片，每支約 1 分鐘）。
  需要自備 ffmpeg（含 libx264 與 libass）；處理時間約 3 到 10 分鐘（依電腦而定）；不安裝則這 5 支影片維持日文，其他部分不受影響。
- 未翻譯：動態漫畫（ADEMO）的英文對話框、廣告圖、KEY HELP 說明書頁面、操作教學截圖（維持日文原圖）。

## 安裝需求
- 自備正版遊戲（Steam）。
- 日文語言包：本繁體中文模組以日文版為基礎，**需自行取得日文語言包**（本專案不提供來源）。安裝程式會偵測遊戲資料夾是否已裝；沒有的話，可指定你自己的日文包資料夾，由安裝程式複製缺少的檔案。
- 影片繁體中文字幕（選用）：需自備 ffmpeg（含 libx264 與 libass）。ffmpeg 是免費的影片處理工具，用來把中文字幕燒進影片；安裝程式不下載、不內附。
- 強烈建議另外安裝 [MGSPatriotFix](https://www.nexusmods.com/metalgearsolidpeacewalkermc/mods/1)（不內附）：遊戲本身不提供切換到日本語的功能，需靠它把遊戲語言切到日本語。

## 安裝
Windows：執行安裝程式，依畫面步驟（免責聲明 → 選擇遊戲資料夾 → 日文包 → 影片選項 → 安裝）。
命令列：`python zhtw_installer.py --cli`（`--auto` 為代勞模式，Linux／SteamOS 預設開啟；可加 `--game` 資料夾、`--jppack` 日文包資料夾、`--ffmpeg` 路徑、`--accept` 表示同意免責聲明；動作為 `install`、`remove`、`remove-all`、`status`）。
SteamOS（Steam Deck）：請看 [SteamOS教學.md](SteamOS教學.md)（手把手教你進入桌面模式、開終端機、執行 `steamos_install.sh`；安裝程式有「代勞模式」，會自動找遊戲資料夾、日文包與 ffmpeg；**未經實機測試**）。

## 日文版／繁體中文模組切換（Beta 0.3 起）
想對照日文原文、或暫時回到日文版時，**不需要移除繁體中文模組**：再次執行安裝程式，選「**切換回日文原版**」，繁體中文模組的檔案會留在遊戲資料夾，遊戲立刻變回日文版；想用中文時再選「**切換為繁體中文模組**」，不需要重新安裝、不需要日文包或 ffmpeg，幾秒內完成。
- 切換只是更名檔案，不會刪除任何東西；原本的「移除繁體中文模組」選項仍然保留（它會刪掉保留的中文檔、確保是日文原版）。
- 保留兩份檔案會多占用約 3 GB 硬碟空間。
- 命令列：`--cli --accept switch-jp`（切回日文）、`--cli --accept switch-zh`（切回中文）。
- 切到日文原版期間，若 Steam 更新或驗證了遊戲檔案，仍可正常切回中文；若切回後發現中文不見，請選「更新／修復」。

## 移除與還原
再次執行安裝程式，選擇「只移除繁體中文模組」（還原被取代的原檔）或「移除繁體中文模組與日文包」（日文包只移除由本程式複製的檔案）。安裝程式會在動手前驗證原檔雜湊，不符就整批拒絕，不會留下半完成的檔案。
也可以用 Steam「驗證遊戲檔案完整性」還原遊戲檔案。
