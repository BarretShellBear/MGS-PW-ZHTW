MGS Peace Walker 繁體中文化 版本沿革

Beta 0.2
- 安裝套件分成 Windows 版（MGSPW_zhTW_Setup.exe，不需要安裝 Python）與 SteamOS 版（Python 腳本＋手把手教學）兩個獨立下載。
- 全面改用「繁中化」用語；說明補充選用的影片繁中化內容（康德引言卡、工作人員名單、捲動名單、兩部年表，共 5 支、10 個檔案）。
- 標明只適用日文版；英文版的繁體中文模組也將會製作。
- 聲明本繁中化包由 AI 協助製作（Anthropic 的 Claude），並經製作者逐步檢視與修正。
- 譯文：第二輪通讀（簡報與劇情）、簡報錄音帶每份第一次出現的人名加原文小字、名詞統一。

Beta 0.1（開發中）
- 適用範圍：僅日文版（需日文語言包）；英文版的繁體中文模組也將會製作。
- 聲明：本繁中化包的翻譯、程式與文件由 AI（Anthropic 的 Claude）協助製作，並經製作者逐步檢視與修正。
- 安裝程式（Windows／SteamOS 共用的 Python 程式）：免責聲明、自動偵測 Steam 遊戲資料夾、日文語言包偵測與安裝（只複製缺少的檔案）、
  繁中化檔安裝（差分補丁，先驗證原檔雜湊再動手）、更新／修復、移除繁中化包、移除繁中化包與日文包。
- 影片繁中化（選用）：需自備 ffmpeg（含 libx264、libass），安裝程式驗證原片後燒入字幕；失敗則保持日文。
- 代勞模式：自動尋找遊戲資料夾、日文包（下載、桌面、USB／SD 卡）與 ffmpeg；Linux／SteamOS 預設開啟。
- SteamOS 教學（手把手，含桌面模式操作）。
- SteamOS 實機測試與 GitHub 發佈尚未完成。
