# Steam Deck／SteamOS 安裝教學（手把手版）

> ⚠️ 製作者沒有 SteamOS 設備，這份教學與 SteamOS 版安裝程式**沒有經過實機測試**。若某一步和你看到的畫面不一樣，請停下來，到 GitHub Issues 回報（附上你卡住的步驟編號與版本號），**不要硬做**。
> 安裝程式在動手前會檢查每個檔案，檢查不過就整批拒絕，不會改壞遊戲；就算出問題，也能用 Steam「驗證遊戲檔案完整性」還原。

> ℹ️ 這個繁體中文模組**只適用於日文版**（需要日文語言包）。

## 開始之前，先準備好這 4 樣東西
- [ ] 已在 Steam 安裝好《METAL GEAR SOLID: PEACE WALKER》（Master Collection 版），而且在 Steam 上看得到「遊玩」按鈕（不是「安裝」）。
- [ ] 你自己的**日文語言包資料夾**（裡面有 FONT、JPN、ms0 三個資料夾）。本專案不提供來源。可以放在 Steam Deck 的「下載」資料夾、桌面，或 USB／SD 卡裡。
- [ ] 本繁體中文模組的壓縮檔（`MGSPW_zhTW_Beta_0.4_SteamOS.zip`）。
- [ ] 電量 50% 以上（或接上充電器），且 Steam Deck 的剩餘空間至少 **3 GB**（若同時要複製日文包，需要約 **19 GB**）。

## 先看這個：怎麼操作桌面模式
桌面模式的操作像一般電腦：
- **滑鼠**：用**右邊觸控板**移動游標；**按下右邊觸控板**（或按 **R2**）＝左鍵點一下；按 **L2** ＝右鍵。
- **觸控螢幕**也可以直接點。
- **叫出鍵盤**：按住 **Steam 鍵**，再按 **X**。要收起來也是同樣按法。

## 步驟（照順序，一步一步來）

### 第 1 步：進入桌面模式
1. 按一下 Steam Deck 的 **Steam 鍵**（左側）。
2. 選最下面的「**電源**」。
3. 選「**切換至桌面**」（英文是 *Switch to Desktop*）。
4. 等幾秒鐘，畫面會變成像電腦桌面。**看到桌面和下方的工作列，就是成功了。**

### 第 2 步：把繁體中文模組放到「下載」資料夾並解壓縮
1. 點桌面左下角的**檔案總管**圖示（一個資料夾的圖案，名稱叫 *Dolphin*）。
2. 左邊點「**下載**」（*Downloads*）。
3. 如果壓縮檔在 USB 隨身碟裡：把隨身碟插上，左邊會出現它的名稱，點進去，把 `MGSPW_zhTW_Beta_0.4_SteamOS.zip` **複製**（右鍵 → 複製），回到「下載」按右鍵 → **貼上**。
4. 在 `MGSPW_zhTW_Beta_0.4_SteamOS.zip` 上按**右鍵** → 選「**解壓縮**（*Extract*）」→ 「**在此解壓縮**（*Extract archive here*）」。
5. 解壓縮完成後，「下載」裡會多出一個資料夾叫 `MGSPW_zhTW_Beta_0.4_SteamOS`。**看到這個資料夾就成功了。**

### 第 3 步：把日文語言包放在好找的地方
- 最簡單：把你的日文包資料夾（裡面有 FONT、JPN、ms0）也**複製到「下載」資料夾**。
- 日文包放在 USB／SD 卡也可以，安裝程式的「代勞模式」會去那裡找。
- 如果你的遊戲已經裝過日文包，這一步可以略過，安裝程式會自己判斷。

### 第 4 步：開啟安裝程式
1. 在檔案總管裡**雙擊進入** `MGSPW_zhTW_Beta_0.4_SteamOS` 資料夾。
2. 在資料夾**空白處按右鍵** → 選「**在此開啟終端機**」（*Open Terminal Here*）。會出現一個黑色（或深色）的文字視窗，這是「終端機」。
3. 按住 **Steam 鍵**再按 **X** 叫出鍵盤，在終端機裡輸入下面這一行（**一個字都不要多、不要少**，大小寫要一樣，空白也要有），然後按鍵盤的 **Enter**：

```
bash steamos_install.sh
```

小技巧：輸入 `bash steam` 之後按一下 **Tab** 鍵，程式會自動幫你補完剩下的字。

4. 稍等幾秒：
   - **出現「MGS Peace Walker 繁體中文模組」的視窗** → 照「第 5 步（視窗版）」做。
   - **沒有視窗，終端機裡直接出現中文文字** → 照「第 5 步（文字版）」做。這代表這台機器沒有視窗元件，一樣可以安裝。
   - **出現「找不到 python3」** → 請回報；SteamOS 正常都內建 python3。

### 第 5 步（視窗版）：照畫面一頁一頁按
視窗右下角有三個按鈕：**上一步**、**下一步**、**取消**。

| 看到的頁面 | 你要做的 |
|---|---|
| **免責聲明** | 先讀完；勾選「**我已閱讀並同意以上聲明**」。下面還有一個「**代勞模式**」，**保持勾選**（程式會自動找遊戲資料夾和日文包，你不用自己找）。按「**下一步**」。 |
| **已偵測到安裝過繁體中文模組**（只有重裝時才會出現） | 想更新或修復就選第一個；想還原就選第二或第三個。按「下一步」。 |
| **選擇遊戲資料夾**（代勞模式找到時會自動跳過） | 如果跳出這一頁，代表沒自動找到：按「**瀏覽…**」，找到 Steam 的 `MGS_PW` 資料夾。預設位置在內建儲存空間是 `home → deck → .local → share → Steam → steamapps → common → MGS_PW`（要先在檔案總管按 **Ctrl + H** 才看得到隱藏資料夾）；裝在 SD 卡則在 `/run/media/…/steamapps/common/MGS_PW`。選好按「下一步」。 |
| **步驟：日文語言包**（每次都會出現） | 如果上面是綠色的「✓ 已偵測到…日文語言包」，不用做任何事，直接按「**下一步**」。如果沒有，代勞模式會自動找；找到時會幫你填好路徑，確認後按「**下一步**」；沒找到時按「**瀏覽…**」，選你放日文包的資料夾（裡面有 FONT、JPN、ms0）。紅字會告訴你缺什麼檔案。 |
| **步驟：影片繁體中文字幕（選用）**（內容：康德引言卡、工作人員名單、捲動名單、兩部年表，共 5 支影片） | 這一頁有兩個選項：「**略過，影片維持日文（建議）**」（預設）和「同時安裝繁體中文影片字幕（需要自備 ffmpeg）」。**直接按右下角的「略過影片並安裝」就好**；SteamOS 預設沒有 ffmpeg，選了第二項會要你指定它的位置。 |
| **安裝中** | 等進度條跑完。複製日文包可能要 **10 到 30 分鐘**，請耐心等，**不要關機、不要睡眠、不要拔 SD 卡或隨身碟**。 |
| **完成** | 看到「安裝完成」就成功了，按「**關閉**」。 |

### 第 5 步（文字版）：照提示輸入
終端機會一行一行問你，**每次輸入完都按 Enter**：
1. 顯示免責聲明後問「輸入 yes 表示同意」：輸入 `yes`（要同意才會繼續）。
2. 程式自動找遊戲資料夾（找不到會請你貼路徑）。
3. 找不到日文包時會停下來並說明；請改用這一行重新執行（把路徑換成你的日文包資料夾）：

```
bash steamos_install.sh --jppack "/home/deck/Downloads/你的日文包資料夾"
```

4. 看到「安裝完成」就成功了。

### 第 6 步：回到遊戲模式
1. 回到桌面，**雙擊**桌面上的「**Return to Gaming Mode**」圖示（綠色，有 Steam 標誌）。
2. 等畫面切換回原本的 Steam Deck 介面。

### 第 7 步：開遊戲檢查
1. 在遊戲庫找到 Peace Walker，按「遊玩」。
2. 遊戲本身不提供切換到日本語的功能，所以才強烈建議安裝 MGSPatriotFix，用它把遊戲語言切到「**日本語**」（繁體中文模組是蓋在日文版資料上，所以要用日文版）。
3. 進到選單與劇情，看到中文就成功了。看到方塊字、漏字或當機，請回報（附版本號，在遊戲資料夾的 `zhtw_version.txt` 裡）。

## 想暫時回日文版、再回中文怎麼辦（Beta 0.3 起）
重新做第 4 步開啟安裝程式，到選單選「**切換回日文原版**」，再按「**下一步**」→「**切換**」。繁體中文模組的檔案會被保留（不是刪除），遊戲變回日文版。想用中文時，重新開安裝程式，選「**切換為繁體中文模組**」即可，不用重新安裝。保留兩份檔案會多占用約 3 GB。

## 想還原、想移除怎麼辦
- **方法一（建議）**：重新做第 4 步開啟安裝程式，到選單選「**只移除繁體中文模組**」（還原被取代的檔案），或「**移除繁體中文模組與日文包**」（日文包只移除由本程式複製的檔案）。
- **方法二（最保險）**：回到遊戲模式 → 在遊戲上按右鍵／選項鍵 → 「屬性」→「已安裝的檔案」→「**驗證遊戲檔案完整性**」。Steam 會把遊戲檔案恢復成官方原樣。

## 常見問題
- **「原始檔案與預期不符，已停止」**：代表遊戲檔案不是預期的版本，或被其他 MOD 改過。請先做「驗證遊戲檔案完整性」，再重新安裝；也要確認日文包版本是對的。
- **「磁碟空間不足」**：請先清出空間（解除安裝不玩的遊戲），再重新安裝。
- **安裝到一半當掉或關機**：直接再執行一次安裝程式，選「更新／修復」；它會從頭驗證並補齊。
- **Steam 更新遊戲後中文不見**：遊戲更新會還原檔案，重新執行安裝程式即可（日文包已在的話只需幾分鐘）。
- **視窗太大或按鈕被擋住**：把視窗往上拖一下，或改用文字版（在終端機執行 `bash steamos_install.sh --cli`）。

## 這份教學用到的名詞對照
| 說法 | 意思 |
|---|---|
| 桌面模式 | Steam Deck 的電腦模式，像一般電腦桌面 |
| 遊戲模式 | 平常用的 Steam Deck 介面 |
| 終端機（Konsole） | 可以輸入文字指令的視窗 |
| 代勞模式 | 安裝程式自動找遊戲資料夾與日文包，找得到的步驟就不再問你 |
| 日文語言包 | 遊戲的日文語言資料，需自行取得（本專案不提供） |
